🔍 搜索引擎分层配置

按顺序尝试，每个引擎独立超时，失败静默跳到下一个。跨域（CORS）受限的引擎在国内直连大概率失败，仅在你自建了代理或有 VPN 时才有意义。

顺序：Tavily → Mojeek → SearxNG → Bing → 维基 → DuckDuckGo。
· 默认启用：Tavily（需 Key）/ Mojeek / 维基，零 Key 兜底也够用。
· SearxNG：仅自建实例可用（公共实例国内不可达）。
· Bing / DuckDuckGo：浏览器 CORS 通常失败，除非走代理。
