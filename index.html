🔑 关于大模型与 API Key

本项目是纯静态页面，没有后端，因此不内置任何大模型密钥。 你需要自备一个兼容 OpenAI 接口的服务，填入页面右上角「⚙️ 设置」。Key 只写入你浏览器自己的 localStorage，不会上传到任何服务器，也不会随页面分发。

✅ 推荐：允许浏览器跨域直连的服务

  • OpenRouter（默认）：聚合数百种模型，官方支持浏览器直连，有免费模型可选
  • 硅基流动 / DeepSeek 等国内网关：多数可用，个别网络环境下可能被跨域策略拦截
  • 自建中转（one-api / new-api 等）：需自行配置 CORS 允许你的 Pages 域名

⚠️ 注意：官方 OpenAI 接口无法直连

  • api.openai.com 的跨域预检会被拦截，浏览器端必然失败
  • 这是官方有意为之（避免密钥暴露在客户端），换任何前端库都无法绕开
  • 如需使用 OpenAI 模型，请通过 OpenRouter 或自建中转接入

未配置大模型时会发生什么？ 页面依然完整可用——会切换到本地规则引擎模式，用关键词匹配直接查询本体论数据并给出结构化结果（师承链、导师排名、学派成员、论文清单等），只是无法进行自然语言任意提问与多步推理。

深度研究（联网检索）：配置大模型后即可使用。检索端采用"双源"设计—— 配置了 Tavily Key 时优先调用 Tavily（结果更全面）； 未配置 Tavily Key 时自动使用 维基百科 / Wikidata 零 Key 兜底（MediaWiki API 与 Wikidata SPARQL 端点原生支持跨域，无需注册即可直接检索人物/奖项/机构的公开资料）， 让"零配置"也能获得外部事实，而不是完全失去联网能力。 未配置大模型时该能力在代码层面不会启用，相关开关保持禁用。

📦 本地运行与部署

全部为静态文件，可直接部署到 GitHub Pages。

# 本地预览（必须通过 HTTP 访问，直接双击打开会受浏览器安全策略限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080/

# 部署到 GitHub Pages
# Settings → Pages → Source 选择分支与根目录即可
# 仓库名会作为访问路径，例如 https://<用户名>.github.io/nobel-kg/
